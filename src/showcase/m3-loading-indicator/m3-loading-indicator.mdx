# Loading indicator

M3's newest progress shape: a blob that morphs through seven forms while it
spins. It is for short waits, under about five seconds, where a spinner would
do but you want something friendlier. For longer or measurable waits, use a
progress bar.

## How the morph works

Morphing between two SVG paths only looks smooth when both paths have the same
number of points in the same order. So every shape is the same kind of curve,
sampled at the same 96 angles:

```ts
// k lobes, each a deep
const radius = (angle) => 1 + a * Math.cos(k * angle);
```

A 5-lobed curve looks like a soft pentagon. A 2-lobed curve looks like a pill.
With matching points, the component can blend any two shapes point by point. It
eases each blend with a small overshoot so it moves like M3's springs, and spins
the whole thing as it goes.

## Wavy progress bar

The other new progress style. The filled part is a rolling sine wave and the
track stays flat, with a gap between them. Give it a `value` from 0 to 100 for
determinate progress, or leave it out for indeterminate.

<Example of={Stories.WavyProgressBar} />
<Controls of={Stories.WavyProgressBar} />

Three details keep it smooth:

- The wave tapers to a flat line at both ends, so its tips meet the track instead of bobbing up and down.
- A new `value` is not a jump. The fill glides to it, at the same speed whatever the frame rate.
- The indeterminate segment's head and tail each ease in and out, and each sweep restarts where both ends are hidden, so the loop has no visible seam.

### Use it in your own app

The `wavy-progress/` folder is self-contained, so copy it as is. The bar fills
the width of its container.

| Input | Default | What it does |
| --- | --- | --- |
| `value` | `null` | 0 to 100 for determinate, `null` for indeterminate |
| `label` | `'Loading'` | The accessible name |
| `amplitude` | `3` | Wave height above and below the centre line, in px |
| `wavelength` | `40` | Length of one wave, in px |
| `thickness` | `4` | Stroke width of the wave and the track, in px |
| `speed` | `0.8` | Waves per second; `0` keeps it still |
| `showStop` | `true` | The dot at the end of a determinate bar |

Recolour it with two CSS variables, which default to Material tokens:

```css
m3-wavy-progress {
  --m3-wavy-progress-indicator-color: var(--mat-sys-tertiary);
  --m3-wavy-progress-track-color: var(--mat-sys-tertiary-container);
}
```

## Accessibility

- Both are `role="progressbar"` with an `aria-label`. The wavy bar also sets `aria-valuenow` when it has a value.
- Under `prefers-reduced-motion: reduce` the shape stops morphing and only rotates slowly, and the wave stops moving.
- The animation runs on `requestAnimationFrame` and stops when the component is destroyed.
